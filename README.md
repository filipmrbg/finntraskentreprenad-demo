# Entreprenad Template

Premium, konverteringsoptimerad webbmall för entreprenad-, mark-, gräv- och byggföretag.

## Snabbstart
```bash
npm install
npm run dev
```

## Konfiguration för ny kund
Använd onboarding-prompten i [`PROMPT_LIBRARY.md`](file:///Users/filipbjorgaas/Coding%20Antigravity%20Templates/Entreprenad-Template/PROMPT_LIBRARY.md) för att anpassa hela webbplatsen för en ny kunddemo i ett enda steg.
